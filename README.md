# Establishing a VPN Connection

A virtual private network (VPN) is a secure and encrypted connection that allows users to access a private network over a public network, typically the Internet. It ensures privacy and data security by creating a tunnel through which data is transmitted, protecting it from potential threats and eavesdropping.

## Lab Objective 
This lab session demonstrates the steps involved in establishing the VPN connection. Upon completion of this lab, you will be able to: 
* Understand the concept of VPN and its importance in network infrastructure.
*  Establish a VPN connection. Lab/Machine Environment You are provided with the Windows virtual machine.
## PART A: Accessing Network & Internet Settings
Open Settings. Navigate to Network & Internet settings and click VPN. 
### STEP 1
From the taskbar, click the Search Windows icon. 
### STEP 2
In the Search Windows text field, type (Settings) and click Settings.
### STEP 3
Click Network & Internet. 
#### STEP 4
Click VPN. 
## PART B: Adding a VPN Connection 
Add a VPN connection with the name ucertifyvpn. Provide the Server name or address as uclabs and ensure that the VPN type is Automatic.
#### STEP 1 
Under VPN, click Add a VPN connection.
### STEP 2 
In the Add a VPN connection window, perform the following steps: 

a.In the VPN provider option, select Windows (built-in).

b.In the Connection name textbox, type (ucertifyvpn) 

c.In the Server name or address textbox, type (uclabs)

d.In the VPN type option, verify that Automatic is selected by default. 

e.Click Save. 
### STEP 3
In the right pane, you will observe a new VPN as ucertifyvpn. 
### STEP 4
Close all windows.
